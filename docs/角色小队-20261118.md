# 工头喵小队与角色设置

日期为 2026-11-18。工头喵为 macOS 任务浮窗提供六个可选猫咪角色。

| 稳定标识 | 角色 | 识别特征 |
| --- | --- | --- |
| foreman | 工头喵 | 橘色毛发、黄色安全帽、完成清单 |
| inspector | 督督喵 | 灰蓝毛发、圆眼镜、蓝色工作服与检查表 |
| fisher | 摸鱼喵 | 奶油毛发、薄荷兜帽、抱着小鱼 |
| electric | 闪电喵 | 深色毛发、紫色耳机、闪电标记 |
| fortune | 发财喵 | 金色毛发、红领巾、成就金币 |
| cosmic | 星舰喵 | 淡紫毛发、透明头盔、宇航服 |

六个角色共用圆润、粗线条的矢量语言，并通过轮廓、配色和道具区分。使用原生绘图，同时用于 20 点菜单栏图标、30–32 点浮窗头像和大尺寸设置预览；无外部图片下载依赖。完成状态使用笑眼表情。

点击菜单栏图标进入主面板。面板上方展示六张单选角色卡片。选择角色后，浮窗、菜单栏和完成庆祝预览同步更新。

设置保存在 `~/.codex/task-manager/settings.json`，由 `mascotID` 记录所选角色，默认选用「工头喵」。

实现：`Sources/Mascot.h` / `Sources/Mascot.m`；设置与庆祝联动位于 `Sources/Celebration.m`；浮窗与菜单栏联动位于 `Sources/TaskPanel.m`。

原生回归测试覆盖角色卡单选、选择恢复、菜单栏和预览同步、206×40 点收起布局，以及完成效果和设置保存。
